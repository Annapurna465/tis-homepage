# Tulas International School — Homepage Redesign

A modern, responsive, animated homepage redesign for Tulas International School (TIS), built as part of the Netpuppys interview assignment.

## 🌐 Live Website

https://tis-homepage-dguyigf4u-visalikaja123-1933s-projects.vercel.app

## 💻 GitHub Repository

https://github.com/Annapurna465/tis-homepage

## ✨ Features

- Responsive design for mobile, tablet, and desktop
- Animated hero section
- Scroll-triggered reveal animations
- Custom cursor for desktop users
- Scroll progress indicator
- Dark / light theme switcher
- Responsive mobile navigation
- Smooth scrolling between sections
- Interactive hover effects
- Admissions call-to-action section
- Contact information section

## 🛠️ Tech Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Lucide React
- JavaScript
